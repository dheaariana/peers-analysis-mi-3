# PEARL MI3

Multi-sector peer discovery prototype for Commercial Risk 3 Group.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

The app searches public web snippets, classifies a target company, ranks comparable companies, logs sources, drafts a NAK paragraph, and exports Excel. A built-in reference database keeps demonstrations usable when public search or scraping is unavailable.

## Important

Use public or approved data only. Automatically extracted results remain pending verification and do not replace Credit Risk Manager judgment.
